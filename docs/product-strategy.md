# Engram Product Strategy

## Positioning

Revenant AI is the company. Engram is the product.

Engram is a privacy-first, local-first self-knowledge product for people who want to capture daily signal, understand their patterns, and build a durable personal memory without handing everything to a cloud silo.

It is not a generic everything-app. It should stay narrow:

- Check in.
- Journal.
- See patterns.
- Ask for grounded insight.
- Grow the Engram replica over time.

## Product thesis

Engram wins when it becomes the private place where a user returns every day to turn lived experience into useful signal.

The core loop is:

1. Capture a daily check-in or note.
2. Reflect through journal, dashboard, and patterns.
3. Use IRIS and Engram to frame personal strengths, shadows, and tendencies.
4. Return tomorrow because the product remembers and improves.

## Paid wedge

The sharp paid wedge should be:

**Private Weekly Review** - a recurring, high-context synthesis of the user's check-ins, journal entries, IRIS profile, and Engram progress.

Why this wedge:

- It maps directly to the existing product loop.
- It does not require social features or broad productivity scope.
- It can start as hosted AI, later support local inference, and still keep the same user promise.
- It is easy to demonstrate through concierge service before full automation.

Free should prove the habit loop. Pro should deepen review, recall, and synthesis.

## Strategic assumptions

- Immediate cash flow should come from services adjacent to Engram.
- Engram should not carry survival pressure before retention is proven.
- Local-first storage is a product differentiator, not an implementation detail.
- Cloud AI is optional acceleration, not the product foundation.
- Local AI should arrive through provider abstraction, not a rewrite.

## Near-term product priorities

1. First-run clarity: explain what Engram learns and what the first action is.
2. Core loop depth: check-in, journal, dashboard, insight, repeat.
3. Provider abstraction: make hosted/local/fallback AI use one contract.
4. Demo readiness: show value without requiring backend configuration.
5. Conversion: make Pro about private review, not generic unlimited tokens.

## Success metrics

- New user completes IRIS or first check-in on day one.
- User returns for a second check-in within seven days.
- User reads at least one useful pattern or review.
- Service clients convert into repeat Engram usage.
- Pro promise can be explained in one sentence.
