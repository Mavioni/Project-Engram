# Product Roadmap

## Mandatory trigger
Use this skill for prioritization, roadmap, release planning, sequencing, or deciding what to build next.

## Contract
- Sequence outcomes, not implementation trivia.
- Keep phases few and concrete.
- Preserve Engram's local-first, privacy-first direction.
- Tie each item to proof of value or risk reduction.

## Workflow
1. Define the target user and objective.
2. Separate now, next, and later.
3. Identify dependencies and stop conditions.
4. Pick the smallest meaningful release.
5. Name the success metric.

## Output
- Objective
- Now
- Next
- Later
- Dependencies
- Success metric
